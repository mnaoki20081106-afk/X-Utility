# X-Utility

Discord上で次の機能を提供するCloudflare Workers BOTです。

- Xシャドウバンチェック
- TOTP 2FAコード生成
- アカウント形式判別・項目別コピー・ログインチュートリアル

## 起動

このリポジトリは `bot-factory.json` に対応しています。Discord-Bot-FactoryからCloudflareへ起動してください。

初回デプロイ後、Discord Developer Portalの **General Information > Interactions Endpoint URL** に次を設定します。

```
https://<Factoryで発行されたWorker URL>/interactions
```

## Xaccount-Bot連携

Xaccount-Bot管理画面からパネルを設置する場合、X-UtilityとXaccount-Botの両方へ同じ `XUTILITY_BRIDGE_SECRET` を設定し、Xaccount-Bot側の `XUTILITY_API_BASE_URL` にX-Utilityの実Worker HTTPS originを設定します。

## 2FA

Discordパネルから2FAキー入力モーダルを開き、標準TOTP（HMAC-SHA1 / 6桁 / 30秒）を生成します。結果はEphemeralで本人だけに表示し、更新・別キー入力にも対応します。シークレットはD1・KV・ログへ保存しません。

## シャドウバン

IRith.ioの現行表示に合わせ、次の6項目を表示します。

- Media Ban
- Search Sensitive Ban
- Search Suggestion Ban
- Search Ban
- Ghost Ban
- Reply Deboosting

Xの公開Web経路から検索・検索候補・会話スレッドの可視性を観測します。取得不能・投稿不足・対象リプライ不足の場合は正常扱いにせず「判定不能 / 対象なし」と表示します。

## アカウント形式判別

Xaccount-Bot管理画面の「X Utility」→「アカウント形式判別」でチャンネルを選び、パネルを設置できます。X-UtilityとXaccount-Botの両方を更新して再起動してください。署名付き設置APIは `/bridge/main/guilds/:guildId/panels/account-format` です。

最初のパネルには「形式判別」「チュートリアル」の2つのDiscordボタンを表示します。どちらもDiscordの入力フォームを開き、納品文字列だけを入力します。買い手に仕入先のFormat・商品ID・ショップ名を入力させません。外部ページへのリンクはありません。結果・形式候補・チュートリアルはEphemeralで本人だけに表示します。判別した値と認証コードは、既存の2FA BOTと同じ太字インラインコードで表示します。値の表示をタップしてコピーしてください。コピー専用の入力フォームは開きません。バッククォートを含む特殊な値はコードブロックで表示し、長い値はDiscordの項目文字数制限に合わせて分割表示します。

フォームの入力はDiscord経由でWorkerが処理します。認証情報はDB・KV・ログに保存せず、表示済みのEphemeralメッセージだけで操作状態を引き継ぎます。メッセージの内容・利用者・15分の期限を署名で検証し、改ざん・別利用者の操作を拒否します。「結果を消す」で元の結果を消去できます。
区切り文字、項目数、値の形、内部の公開形式カタログを組み合わせて自動判別します。複数の解釈が成り立つ場合も、仕入先の形式選択や手入力は求めず、確定できない項目を候補として表示します。空欄とパスワードの空白を保持します。ログインやキーの有効性は検証しません。

HStoraは2026-10-04時点のXカテゴリ全15ページ、175商品、75ショップを調査し、明確な表記がある119商品の形式を登録しています。形式未記載・曖昧な商品、将来の新規出品を含む「全商品を常に完全自動判別」は保証できません。hStockPlusは全36ページ・1,053商品・102ショップを調査し、47ショップ・516商品の形式（139構造、299表記）を追加しています。調査範囲と未確定商品は `docs/account-format-coverage.md` と `docs/hstockplus-format-coverage.md` を参照してください。

`npm run typecheck` はブラウザ用スクリプトを生成した上でWorker・ブラウザの型を確認します。`npm test` は登録形式・候補衝突・コピー内容・通信/保存なしの画面テストを実行します。

## ログインチュートリアル

最初の「チュートリアル」ボタンから納品文字列を入力すると、判別結果をログイン手順に差し込みます。「形式判別」の結果からも表示できます。候補が複数ある場合も仕入先の情報は求めません。推定・重複を含むログイン情報は確認フォームでX登録メール・ユーザー名・Xパスワード・2FAキーを確認してから進みます。

チュートリアル内で標準TOTP（SHA1・6桁・30秒）を生成できます。Discordの相対時刻表示で次の更新までの期限を表示し、「2FAコードを更新」で再生成します。Discord内ではコピーボタンの毎秒カウントダウンや無操作での継続的なコード再生成は行いません。表示済みコードの期限を確認し、期限後は更新ボタンで新しいコードを生成してください。

以前設置した外部ページへのリンクパネルは、管理画面から新しいパネルを設置してください。
